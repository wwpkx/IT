## 核心总结

- 线性回归：输出连续值，MSE损失；
- 逻辑回归：输出概率，交叉熵损失。
- 根源：一个拟合连续标签，一个拟合0/1概率标签。
- 约定：**w 是列向量**，所以单样本写成 $w^T x$

## 通俗类比

- 线性回归：打分直接当预测结果，目标是：分数贴近真实数值；
- 逻辑回归：先打分，再把分数压成0~1的概率，目标是：概率贴合0/1标签。

| 对比环节 | 线性回归 | 逻辑回归（二分类） |
| --- | --- | --- |
| **任务类型** | 回归，预测连续数值 | 分类，预测属于正类的概率 |
| **标签y** | 实数，$y\in \mathbb R$ | 离散，$y\in{0,1}$ |
| **线性部分（logit）** | $z = w^Tx=w_0+w_1x_1+\dots$   直接作为预测值 | $z = w^Tx=w_0+w_1x_1+\dots$   叫logit，不是最终输出 |
| **激活函数** | 无激活，$\hat y = z$ | Sigmoid：$\displaystyle \hat y=\sigma(z)=\frac{1}{1+e^{-z}}$，映射到$((0,1))$ |
| **预测表达式** | $\hat y_i = w^Tx_i$ | $\displaystyle \hat y_i=\frac{1}{1+e^{-w^Tx_i}}$ |
| **概率解释** | 无概率含义，只是数值 | $\hat y_i=P(y_i=1\mid x_i;w)$，正类概率 \n 给定这个样本特征 \(x_i\)，在参数 w 这套模型下，标签等于 1 的概率 |
| **损失函数** | 均方误差MSE   $\displaystyle J(w)=\frac1N\sum_{i=1}^N(\hat y_i-y_i)^2$ | 二元交叉熵（负对数似然）   $\displaystyle J(w)=-\frac1N\sum_{i=1}^N\big[y_i\ln\hat y_i+(1-y_i)\ln(1-\hat y_i)\big]$ |
| **损失凸性** | MSE损失是凸函数 | 交叉熵损失是凸函数 |
| **导数化简前** | $\displaystyle \frac{\partial J}{\partial w_j}=\frac1N\sum 2(\hat y_i-y_i)x_{ij}$ | 链式法则，先对$\hat y$求导、再sigmoid导数、再对$z$求导 |
| **最终梯度公式** | $\displaystyle \frac{\partial J}{\partial w_j}=\frac{2}{N}\sum_{i=1}^N (\hat y_i-y_i)x_{ij}$ | $\displaystyle \frac{\partial J}{\partial w_j}=\frac1N\sum_{i=1}^N (\hat y_i-y_i)x_{ij}$ |
| **梯度下降更新** | $w_j:=w_j-\alpha\cdot \displaystyle\frac{2}{N}\sum(\hat y_i-y_i)x_{ij}$ | $w_j:=w_j-\alpha\cdot \displaystyle\frac{1}{N}\sum(\hat y_i-y_i)x_{ij}$ |
| **预测判别** | 直接输出数值，不需要阈值 | 常用阈值0.5：$\hat y\ge0.5\Rightarrow$类别1，否则0 |
| **底层优化思想** | 最小化预测值和真实值距离 | 最大化似然，让现有标签出现概率最大 |
| **常见评估指标** | MAE、RMSE、$R^2$ | Accuracy、Precision、Recall、F1、AUC |
| **容易出问题场景** | 离群点对MSE影响很大 | 样本不平衡时准确率不可靠，优先看AUC |

### 关键补充说明

1. 梯度看着几乎一样，差别来源：
   - 线性回归 $\hat y = w^Tx$
   - 逻辑回归 $\hat y = \sigma(w^Tx)$
   虽然式子 $(\hat y-y)x$ 结构一致，但$\hat y$的生成方式完全不同。
2. 为什么逻辑回归不用MSE：
sigmoid+MSE组合后损失函数**非凸**，会出现大量局部最优，梯度下降容易卡住；交叉熵规避了这个问题。
3. 共同优点：损失都是凸函数，合适学习率下梯度下降可以找到全局最优。
