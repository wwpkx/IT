# 深度学习
- 一句话总述
    - 深度学习 = 用多层神经网络自动学习特征，不用人工大量做特征工程
    - 属于机器学习的一个子集
    - 监督/无监督/强化学习都可以用神经网络实现
    
## 神经网络基础
	- 神经元（感知机）
		- 通俗解释：模仿人脑一个神经细胞，接收输入、加权求和、再判断输出一个结果
		- 权重 weight
			- 通俗解释：每个输入信息的重要程度，模型训练就是不断调整权重
		- 偏置 bias
			- 通俗解释：给神经元加一个“基础门槛”，控制神经元多容易被激活
		- 激活函数
			- 通俗解释：给神经元加入非线性能力；没有它，再多层网络也只能做线性回归
			- Sigmoid
				- 通俗解释：把数值压缩到0~1之间，适合输出概率；缺点容易梯度消失
			- ReLU
				- 通俗解释：负数直接归零，正数原样输出；现在最常用，计算简单、不容易梯度消失
			- Tanh
				- 通俗解释：压缩到-1~1，中心化，早期常用
			- Softmax
				- 通俗解释：把一堆数字转成加起来等于1的一组概率，多分类输出用
	- 单层神经网络
		- 通俗解释：只有输入层+输出层，能力很弱，只能处理简单线性问题
	- 多层神经网络（全连接网络 DNN）
		- 通俗解释：输入层、隐藏层、输出层层层相连；隐藏层就是自动提取特征的地方
			- 输入层：原始数据（图片像素、文本数字向量）
			- 隐藏层：模型自动提炼特征，不需要人手动设计特征
			- 输出层：给出最终预测（分类概率、回归数值）
## 训练核心机制
	- 前向传播
		- 通俗解释：数据从输入层一路算到输出层，得到本次预测结果
	- 反向传播 Backpropagation
		- 通俗解释：对比预测和真实答案，从后往前一层层算误差，告诉每个权重该调大调小
	- 梯度下降（深度学习版本）
		- 通俗解释：顺着误差山坡往下走，一点点修改权重，让预测误差变小
		- 学习率
			- 通俗解释：每次下山迈多大步子；步子太大容易冲过头，太小走得太慢
		- 小批量梯度下降 Mini-batch
			- 通俗解释：不拿全部数据、也不拿单条数据，一小批一小批喂给网络训练
	- 损失函数
		- 通俗解释：衡量预测结果和标准答案差得多远的打分器
		- 交叉熵损失
			- 通俗解释：分类任务最常用，衡量两个概率分布差距
		- MSE均方误差
			- 通俗解释：回归任务，衡量预测数字和真实数字的距离
	- 优化器 Optimizer
		- 通俗解释：梯度下降的升级版“下山策略”，自动调节学习率、加速收敛
		- SGD
			- 通俗解释：基础随机梯度下降，稳定但是慢
		- Adam
			- 通俗解释：最常用的优化器，自适应调整学习率，省心好用
## 正则化（防过拟合）
	- Dropout
		- 通俗解释：训练的时候随机关掉一部分神经元，防止网络过度死记训练集
	- 早停 Early Stopping
		- 通俗解释：验证集效果不再变好就立刻停下，不继续训练，避免背答案
	- L1 / L2正则
		- 通俗解释：给大权重加惩罚，鼓励权重变小，简化模型
	- 数据增强
		- 通俗解释：原图翻转、裁剪、微调亮度，凭空造出更多训练样本，减少过拟合
## 经典网络结构
	- CNN 卷积神经网络（主打图像）
		- 通俗解释：专门看图的网络，用卷积核扫描图片，自动抓边缘、纹理、轮廓
		- 卷积层 Conv
			- 通俗解释：滑动小窗口（卷积核）提取局部图像特征
		- 池化层 Pooling
			- 通俗解释：把特征图缩小，保留关键信息，减少计算量
		- 填充 Padding
			- 通俗解释：图片外围补一圈0，控制卷积后图片大小不变
		- 步长 Stride
			- 通俗解释：卷积核每次滑动跳过几个像素
	- RNN 循环神经网络（主打时序、序列）
		- 通俗解释：处理一串先后有关系的数据（一句话、一段时间序列），记住前面信息
		- LSTM
			- 通俗解释：RNN改进版，专门解决记不住久远信息的问题，适合长句子
		- GRU
			- 通俗解释：LSTM简化版，效果接近，速度更快
	- Transformer
		- 通俗解释：依靠自注意力机制，一次性看整个序列，不依赖顺序循环；现在大模型底座
		- 自注意力 Self-Attention
			- 通俗解释：让每个词看懂和句子里其他词的关联，抓长距离关系
		- 多头注意力 Multi-head Attention
			- 通俗解释：多组注意力，同时看多种关系（语法、语义）
		- 位置编码 Positional Encoding
			- 通俗解释：给序列加上顺序信息，告诉模型哪个词在前、哪个在后
## 训练相关概念
	- 轮次 Epoch
		- 通俗解释：把全部训练数据完整跑一遍，叫1个epoch
	- 批次 Batch
		- 通俗解释：一次喂给模型的一小份数据
	- 迭代 Iteration
		- 通俗解释：跑完一个batch，完成一次参数更新
	- 梯度消失
		- 通俗解释：网络很深的时候，误差传到前面几乎变成0，权重不再更新，学不动
	- 梯度爆炸
		- 通俗解释：梯度数值变得巨大，参数剧烈震荡，模型很难收敛
	- 收敛
		- 通俗解释：误差不再明显下降，模型基本稳定，学的差不多了
## 评估 & 特殊任务概念
	- 嵌入 Embedding
		- 通俗解释：把文字、类别这种符号，转成一组数字向量，相近含义的向量距离近
	- 预训练 Pre-training
		- 通俗解释：先用海量通用数据先学基础能力，再拿小数据做微调
	- 微调 Fine-tune
		- 通俗解释：在已经学好的大模型上，用自己少量数据继续训练适配你的任务
	- 提示学习 Prompt Learning
		- 通俗解释：不改动模型权重，靠写提示词引导模型输出想要的结果
	- 迁移学习
		- 通俗解释：把A任务学到的能力，迁移到B任务，小数据集也能学好
	- 生成模型
		- 通俗解释：不是判断分类，而是从头生成新内容（图片、文字、音频）
		- VAE
		- 通俗解释：变分自编码器，学习数据分布，用来生成图片
		- GAN
			- 通俗解释：对抗生成网络，一个生成、一个判别，互相博弈进步
		- Diffusion 扩散模型
			- 通俗解释：逐步给图片加噪声，再反向去噪生成图像，现在画图主流
## 常见术语
	- 权重初始化
		- 通俗解释：训练开始前，给权重一个合适初始值，避免一开始就学不动
	- 归一化（BN层 BatchNorm）
		- 通俗解释：把每一层的输出拉回稳定分布，加快训练、不容易梯度消失
	- 编码器 Encoder
		- 通俗解释：把输入压缩成浓缩特征向量
	- 解码器 Decoder
		- 通俗解释：从浓缩特征向量还原、生成输出
	- 编码器-解码器架构 Encoder-Decoder
		- 通俗解释：先压缩信息，再生成输出，翻译、画图常用结构
