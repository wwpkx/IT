# 线性回归模型评估

## 核心总结

- 线性回归的拟合前提：假设特征和标签之间存在**线性关系**
- 评估分为两块：一是检验线性假设是否成立，二是用指标衡量模型预测准不准
- 评估的目的：判断模型有没有学到真实规律，是欠拟合、合适还是过拟合。

## 通俗类比

- 线性回归好比用一根直尺去贴合一堆散点。
- 评估：
  - 看这些点本身是不是大致沿着一条直线分布（拟合前提）
  - 看这根直尺贴得好不好，预测误差大不大

## 一、线性回归四大经典拟合前提（高斯-马尔可夫假设）

- 1. 线性性
  - 通俗解释：自变量x和目标y之间存在线性关系
  - 检验方法：画散点图，看x和y是否近似一条直线；看残差图
  - 例子：面积和房价大致是直线趋势；如果是曲线关系，直接用线性回归不合适
- 2. 残差零均值
  - 通俗解释：误差没有固定偏向，不会整体普遍偏大或者普遍偏小
  - 检验方法：残差均值接近0，残差图在y=0上下均匀分布
- 3. 残差同方差（齐方差性）
  - 通俗解释：误差的波动大小不随x变化，不会x越大误差明显变大
  - 检验方法：残差图，横向看上下宽度是否一致
  - 反例：房价越大，预测误差越来越大 → 异方差，会影响置信区间
- 4. 残差无自相关
  - 通俗解释：一条样本的误差，不会影响下一条样本的误差（时序数据最容易踩坑）
  - 检验方法：DW检验
  - 例子：按月销量预测，上个月高估，这个月也高估，就是自相关
- 附加假设：残差正态分布（做t检验、置信区间时需要）
  - 通俗解释：误差服从正态分布
  - 检验：Q-Q图、直方图

## 二、回归常用评估指标（用来衡量预测好坏）

- MAE 平均绝对误差
  - 通俗解释：预测值和真实值差值的绝对值求平均，直观、不容易被极端值带偏
  - 特点：单位和原始y一致
  - 例子：MAE=5万，代表房价平均预测偏差5万元
- MSE 均方误差
  - 通俗解释：误差平方之后求平均，放大大误差，惩罚离谱的预测
  - 特点：对异常值敏感
- RMSE 均方根误差
  - 通俗解释：MSE开根号，单位和y一致，最常用
  - 例子：RMSE=6万，平均偏离大约6万
- $R^2$ 决定系数（最核心）
  - 通俗解释：模型能解释目标y多少比例的波动
  - 取值范围：$(-\infty,1]$
  - $R^2=1$：完美拟合；$R^2=0$：和直接取平均值效果一样；负数：模型还不如直接用均值预测
  - 例子：$R^2=0.82$，代表特征可以解释82%房价的波动

## 三、欠拟合 / 合适 / 过拟合判断

- 欠拟合
  - 表现：训练集R²很低，测试集R²也很低
  - 原因：模型太简单，或者违背线性假设（真实关系是曲线）
  - 例子：散点明显是曲线，硬拉一条直线拟合
- 拟合恰当
  - 表现：训练集、测试集R²接近，误差都比较小
  - 残差图均匀、无规律
- 过拟合
  - 表现：训练集R²很高，测试集R²明显下降，差距很大
  - 原因：特征太多、混入噪声，模型学到了训练集独有的随机噪声
  - 线性回归里过拟合常用L1/L2正则（Ridge、Lasso）解决

## 四、残差图（可视化评估，强烈推荐）

- 横轴：预测值$\hat y$；纵轴：残差 $y-\hat y$
- 理想效果：点均匀散乱分布在0横线上下，没有明显形状、趋势
- 异常信号
  - 出现抛物线弧线：不满足线性假设
  - 喇叭形状：异方差
  - 连续向上/向下长条：残差自相关

## 五、实操流程顺序

- 1. 先检验前提：散点图、残差图，确认线性等假设大致成立
- 2. 再计算R²、RMSE等指标
- 3. 对比训练集、测试集指标，判断是否过拟合
- 4. 不满足前提时的处理方案
  - 非线性：增加多项式特征、对数变换
  - 异方差：对数变换、加权最小二乘
  - 多重共线性：VIF方差膨胀因子检验，剔除高度相关特征

## 六、补充：多重共线性（线性回归特有坑）

- 通俗解释：多个特征之间高度线性相关，信息重复
- 危害：参数w不稳定，解释混乱，梯度下降震荡
- 检验：VIF，VIF>5~10说明共线性严重
- 例子：同时放“平米面积”和“平方英尺”两个特征

## 七、简单对比

- R²：看整体解释能力（优先看）
- RMSE：看平均偏差大小（业务直观）
- 残差图：看假设是否成立（判断模型能不能用）
- VIF：检查特征之间是否互相干扰
