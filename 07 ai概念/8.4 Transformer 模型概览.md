# Transformer 模型概览
- **Transformer 是一种以注意力机制为核心的深度学习架构**
- 最早用于自然语言处理，如今已广泛应用于大语言模型、图像、语音和多模态 AI。
- GPT、BERT、T5、Qwen、Llama 等许多模型，都以 Transformer 或其变体为基础。

# Transformer 的优点
- 计算可并行化：相比 RNN，Transformer 在训练阶段可以同时处理大量 Token，更适合 GPU 和大规模训练。
- 擅长长距离依赖：Transformer 可以直接建立序列中任意位置之间的关联。
- 适用于多种模态，比如文本； 代码； 图像； 视频；

# Transformer 的局限
- 计算成本高
- 可能产生幻觉
- 上下文窗口有限
- 缺乏真实执行能力：Transformer 本身主要负责计算和生成，需要工具和系统连接才能执行操作。
- 训练成本高

# 一、Transformer 解决了什么问题
- Transformer 使用 **Self-Attention（自注意力）**，可以同时处理整个序列，并判断不同词之间的关联程度。

在 Transformer 之前，文本通常使用 RNN、LSTM 等循环网络处理，这种方式存在两个主要问题：
1. 必须按顺序处理，难以并行计算；
2. 处理长文本时，较早的信息可能逐渐丢失。

# 二、Transformer 的核心：Attention

## 1. Self-Attention
- 自注意力会让序列中的每个词关注其他相关词。
- 它不是只看相邻词，而是计算当前词与其他词之间的相关程度。

## 2. Query、Key、Value
可以直观理解为：计算相关性 → 转换为权重 → 加权汇总信息

自注意力通常使用三个向量：
- **Query（Q）**：当前 Token 想寻找什么信息；
- **Key（K）**：每个 Token 可以被匹配的特征；
- **Value（V）**：真正要传递的内容。

# 三、Transformer 的基本结构
经典 Transformer 由 **Encoder** 和 **Decoder** 两部分构成：

```text
输入文本
   ↓
Token Embedding
   ↓
位置编码
   ↓
Encoder
   ↓
Decoder
   ↓
输出文本
```

# 四、Transformer Block 的主要组件

```text
输入
 ↓
多头自注意力
 ↓
残差连接 + LayerNorm
 ↓
前馈神经网络
 ↓
残差连接 + LayerNorm
 ↓
输出
```

## 1. Multi-Head Attention
Transformer 不只做一次注意力，而是使用多个注意力头，从不同角度理解信息，例如：
- 语法关系；
- 主谓关系；
- 指代关系；
- 长距离依赖；
- 语义关联。

## 2. Feed-Forward Network
- 它帮助模型提取更复杂的特征。

对每个位置的表示进行非线性变换，通常结构类似：

```text
线性层 → 激活函数 → 线性层
```

## 3. Residual Connection
残差连接将输入直接加到子层输出上：
这样可以缓解深层网络训练中的梯度问题和信息丢失。

## 4. Layer Normalisation
Layer Normalisation 对中间表示进行归一化，有助于提高训练稳定性。

## 5. Positional Encoding
Transformer 本身不像 RNN 那样天然理解顺序，因此需要加入位置信息：

```text
Token 表示 + 位置表示
```

# 五、三种主要 Transformer 结构

| 结构 | 代表模型 | 主要用途 |
|---|---|---|
| Encoder-only | BERT | 理解、分类、检索、信息抽取 |
| Decoder-only | GPT、Qwen、Llama | 文本和代码生成 |
| Encoder-Decoder | T5 | 翻译、摘要、文本转换 |


# 六、GPT 类模型如何使用 Transformer
GPT 类模型通常是 Decoder-only Transformer。它的训练目标是：
> 根据前面的 Token，预测下一个 Token。
