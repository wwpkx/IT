# AI Agent 分类
- 按业务领域：Code、Research、Data、Customer Service、Finance、HR、IT Operations 等；
- 按自治程度：Copilot、Assistant、Workflow Agent、Autonomous Agent；
- 按系统结构：Single Agent、Multi-Agent、Hierarchical Agent；
- 按技术能力：Knowledge、Tool-Using、Browser、Computer-Use、Code Execution Agent。
