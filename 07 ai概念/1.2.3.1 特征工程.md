# 特征工程

## 核心总结

- 特征工程，就是从原始数据里筛选、改造、创造出更好的输入特征
- 目的是让机器学习模型更容易学到数据里的真实规律。
- 简单来说：给模型喂什么信息，模型就学到什么；差的特征再强的模型也学不好。

## 通俗类比

- **模型好比厨师，特征就是食材。**
- 原始数据是一堆原材料，特征工程就是加工食材：挑选有用食材、去掉杂质、切成合适大小、组合出新食材；

## 一、特征分类

- 数值特征
  - 通俗解释：可以直接加减计算的数字，分连续型、离散数值
  - 连续型：房价、面积、温度、收入
  - 离散数值：房间数量、交易次数
- 类别特征（分类特征）
  - 有序类别：自带顺序关系，如：小学<中学<本科<硕士
  - 无序类别：没有大小顺序，如：城市、颜色、支付方式
- 时间特征
  - 通俗解释：时间戳本身数字没有意义，需要拆解成有业务含义的信息
  - 例子：下单时间 → 年、月、星期、小时、是否周末、是否节假日
- 文本特征
  - 通俗解释：原始文字不能直接丢给模型，需要转化成数字向量
  - 例子：用户评价文本 → 词袋、TF-IDF、词嵌入
- 布尔特征
  - 通俗解释：只有两种状态，是/否
  - 例子：是否VIP、是否逾期、是否有房产证

## 二、特征构建（创造新特征）

- 算术组合特征
  - 通俗解释：对已有特征做加减乘除，生成业务含义更强的新特征
  - 例子
    - 房价 / 面积 = 单价
    - 总收入 - 总支出 = 结余
    - 销售额 / 访客数 = 转化率
- 时间衍生特征
  - 例子
    - 当前日期 - 注册日期 = 用户注册时长
    - 提取小时：判断是白天下单还是夜间下单
- 统计聚合特征（分组特征）
  - 通俗解释：按某维度分组，计算组内均值、最大值、最小值、计数
  - 例子
    - 按用户分组：该用户历史平均消费、最大单笔消费
- 比例、差分特征
  - 例子：本月销量 / 上月销量 = 环比增长率

## 三、特征编码（类别特征转数字，核心高频操作）

- 标签编码 LabelEncoder
  - 通俗解释：给类别依次分配0,1,2,3……
  - 适合：有序类别（存在大小顺序）
  - 不适合：无序类别，会让模型误以为数字有大小关系
  - 例子：学历：小学=0，中学=1，本科=2，硕士=3
- 独热编码 OneHotEncoder
  - 通俗解释：一个类别扩展成多列，对应位置标记1，其余0
  - 适合：无序类别，城市、颜色、商品品类
  - 缺点：类别很多时，特征会爆炸，维度变很大
  - 例子：广州、上海、北京 → 广州[1,0,0]，上海[0,1,0]
- 序数编码 OrdinalEncoder
  - 和标签编码类似，支持多列有序特征
- 目标编码 TargetEncoder
  - 通俗解释：用该类别对应的标签平均值作为编码值
  - 适合：类别非常多（高基数类别），比如用户ID、门店ID
  - 注意：需要防止数据泄露
- 频率编码
  - 通俗解释：用该类别出现的频次占比作为特征
  - 例子：某个城市样本占全部数据20%，该城市就填0.2

## 四、特征变换（改变数值分布，适配模型）

- 归一化 Min-Max Scaling
  - 通俗解释：把数值压缩到 [0,1] 区间
  - 公式：$x_{new}=(x-min)/(max-min)$
  - 适合：知道数值上下限、神经网络
  - 缺点：对异常值非常敏感
- 标准化 Z-score Standardization
  - 通俗解释：变换成均值为0、标准差为1的分布
  - 公式：$x_{new}=(x-\mu)/\sigma$
  - 适合：线性回归、梯度下降、SVM、逻辑回归
  - 不适合：树模型
- 对数变换 log
  - 通俗解释：把右偏、长尾的数据拉平缓，减少大数值的影响
  - 例子：收入、订单金额这类长尾数据
- 幂变换（Box-Cox、Yeo-Johnson）
  - 通俗解释：修正偏态分布，让数据更接近正态分布

## 五、特征筛选（剔除没用、冗余特征，减少噪声）

- 过滤式筛选
  - 方差筛选：剔除方差接近0的特征，所有样本值几乎不变，没有区分能力
  - 相关性筛选：和目标标签相关性极低的直接删掉；两个特征高度相关，只保留一个
  - 例子：面积和平方英尺高度相关，删掉其中一个
- 包裹式筛选
  - 通俗解释：用模型效果来挑选特征，尝试不同组合，看哪个组合效果最好
  - 代表：递归特征消除 RFE
- 嵌入式筛选
  - 通俗解释：模型训练过程自动做特征选择
  - 例子：L1正则（Lasso），会把不重要特征权重压缩到0
- 业务筛选
  - 通俗解释：基于业务常识直接剔除无关特征
  - 例子：预测房价，用户的手机号、用户名没有预测价值，直接删掉

## 六、特征降维（特征太多时，压缩信息）

- PCA 主成分分析
  - 通俗解释：把大量高度相关的特征，重新组合成少数几个新的综合特征
  - 特点：新特征失去原有业务含义，属于信息压缩
  - 适合：特征数量巨大、特征之间相关性强
- t-SNE、UMAP
  - 多用于可视化，一般不用于训练模型输入

## 七、重要避坑点

- 编码坑：无序类别随便用标签编码，模型会错误理解顺序关系
- 缩放坑：树模型（决策树、随机森林、XGBoost）不需要归一/标准化，做了没有收益
- 泄露坑：缩放、目标编码，**必须只用训练集统计信息**，不能用全量数据
- 维度爆炸坑：类别很多的时候慎用独热编码
- 业务脱离坑：只看数学指标，造出来的特征完全不符合业务逻辑，泛化差

## 八、模型适配小总结

- 线性回归、逻辑回归、SVM、神经网络：依赖缩放，类别优先独热编码
- 树模型（XGBoost、LightGBM）：不用缩放；高基数类别优先目标编码
- 时序模型：重点挖掘时间衍生特征
- 大基数ID类特征：优先目标编码、频率编码，避开独热编码
