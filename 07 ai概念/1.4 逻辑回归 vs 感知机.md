# 逻辑回归 vs 感知机
- 感知机可以看作逻辑回归的一个更简单、更弱的线性分类版本，但两者不是严格的包含关系
- 感知机可以看作功能更简单、表达能力和输出能力较弱的线性二分类模型；
- 逻辑回归则是在相同线性骨架上，通过 Sigmoid、交叉熵和梯度优化实现概率预测的模型。

# 总结对比

| 对比维度 | 感知机 | 逻辑回归 |
|---|---|---|
| 模型输出 | 硬标签 | 概率 |
| 激活函数 | 阶跃函数 | Sigmoid |
| 损失函数 | 感知机损失 | 交叉熵损失 |
| 更新条件 | 通常只在错分时更新 | 根据概率误差持续更新 |
| 标签形式 | 常用 $-1,+1$ | 常用 $0,1$ |
| 是否提供概率 | 否 | 是 |
| 对不可分数据的表现 | 可能震荡 | 通常更稳定 |
| 是否便于阈值调整 | 较弱 | 较强 |
| 解释能力 | 主要解释分类边界 | 可解释概率、对数几率和优势比 |
| 适合场景 | 简单硬分类、教学 | 概率预测、风险评分、生产应用 |

# 训练流程的核心对照

| 步骤 | 感知机 | 逻辑回归 |
|---|---|---|
| 1. 输入样本 | $x_i,y_i$ | $x_i,y_i$ |
| 2. 线性计算 | $z=w^\top x+b$ | $z=w^\top x+b$ |
| 3. 输出转换 | 阶跃函数 | Sigmoid |
| 4. 输出结果 | 硬标签 | 概率 |
| 5. 计算误差 | 判断是否错分 | 计算 $p-y$ |
| 6. 损失 | 感知机损失 | 交叉熵 |
| 7. 参数更新 | 只在错分时更新 | 通常每次按概率误差更新 |
| 8. 停止依据 | 无错分或达到上限 | 损失收敛或达到上限 |
| 9. 最终预测 | 直接输出类别 | 概率再通过阈值转为类别 |

# 最简洁的流程记忆

## 感知机

$$
\text{输入}
\rightarrow
\text{线性计算}
\rightarrow
\text{硬分类}
\rightarrow
\text{判断对错}
\rightarrow
\text{错了才更新}
$$

## 逻辑回归

$$
\text{输入}
\rightarrow
\text{线性计算}
\rightarrow
\text{Sigmoid概率}
\rightarrow
\text{计算交叉熵}
\rightarrow
\text{计算梯度}
\rightarrow
\text{按概率误差更新}
$$
