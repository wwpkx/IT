# 强化学习与监督学习对比
## 核心一句话区别
- 监督学习：拿着大量【输入+标准答案】的例题，学会直接背映射
- 强化学习：没有标准答案，靠和环境互动试错、奖惩，慢慢摸索最优动作

## 通俗类比
- 监督学习：做习题集，每道题后面都有参考答案，对照答案改错
- 强化学习：学骑车，没人告诉你每一刻手把要转多少，摔了就是惩罚，骑稳了就是奖励，慢慢练会平衡

## 监督学习
- 数据特点
    - 训练数据自带标签（标准答案）
    - 一次样本 = 输入 + 确定结果
- 学习目标
    - 学到：输入 → 标准答案 的固定映射
- 学习方式
    - 一次性批量学习样本，独立学习每一条数据
- 适合场景
    - 分类、数值预测
- 例子
    - 给一堆猫狗标注好的图片，训练模型识别猫/狗
    - 给历史房价数据，训练模型预测房价

## 强化学习
- 数据特点
    - 没有标准答案，只有环境反馈（奖励/惩罚）
    - 数据是连续序列：动作→环境变化→获得奖励
- 学习目标
    - 学到一套策略：在不同状态下，选哪个动作拿到最多奖励
- 学习方式
    - 和环境持续交互、连续试错，当前动作会影响后续状态
- 适合场景
    - 连续决策、控制类任务
- 例子
    - AlphaGo下棋，落子之后等到棋局结束才知道输赢（奖励）
    - 机器人走路，摔倒扣分、平稳前进加分，慢慢学会走路
